generated architecture, terrain splines, the old probe lighting and the phase-42 surface cache, WebGL 2), kept at
their old relative paths. Archived in phase 47T before the systems' code goes (phase 48): that code is untested
until then. Not run or collected by anything. Listed in `docs/inventory-47t-ledger.md`.
