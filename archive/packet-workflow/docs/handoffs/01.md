## Outcome

`docs/contracts/project-model.md` v0.2 defines the M1 logical manifest/scene,
IDs, version taxonomy, Y-up right-handed meters, local transforms, XY gameplay
plane with depth Z, Transform/box/camera components, hierarchy/deletion rules,
validation, canonicalization, and identity-only migration entry points.

The owner's request to fix the review of `017ae9d` and `42277a0` produced four
explicit corrections before Gate A acceptance:

1. **Storage:** standalone files are interchange/fixture documents. Active
   `scenes/main.json` is reserved for packet 02's single atomic envelope
   containing the scene (including the project revision) and retry metadata.
   No second authoritative bare scene or independently mutable revision.
   Envelope fields/version, ownership records, temp files, and recovery remain
   packet 02's responsibility. The model validates the embedded logical scene.
2. **Quaternions:** retain accepted components within the existing `1e-4`
   norm tolerance; canonicalize negative zero, but do not renormalize authored
   rotations. Rendering normalizes a derived copy only. A regression fixture
   and exact canonical golden pin roundoff-sensitive q/−q and near-unit values
   on both sides of 1. This avoids repeated-normalization floating-point drift.
3. **Parsing:** pure `parseManifest/parseScene(Uint8Array)` entry points own
   encoding, syntax, and escaped duplicate-name checks, then invoke value
   validation. `validate*` takes values and cannot recover discarded lexical
   information. Added BOM/malformed-UTF-8, duplicate, syntax-precedence, and
   retained-input byte cases. Corrected the related overflow guidance: valid
   JSON `±1e400` becomes non-finite and fails value validation, not syntax.
4. **Versions:** unsupported versions stop their own document's validation;
   project errors carry document attribution, manifest before scene. Cross-
   document checks run only after both pass. Removed unreachable M1
   `schema_mixed_versions`; added a mixed-version fixture and precedence cases.

Logical schemaVersion remains `1`: this is an explicitly recorded correction
of an unaccepted contract, with no implemented readers. Gate A remains open.
