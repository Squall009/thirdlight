## Outcome

The editor can author every M3 media/lighting/animation value through the
accepted commands, with a pure planning layer, an imperative three.js preview
and the packet's self-contained preview-audio surface:

**`src/session/media.ts`** (new, pure — no DOM/Node/clock): `validateMediaDrop`
(`.glb`→model / `.wav`→audio, 1…32 MiB stage bound; invalid drop creates no
stage/job); `planCueEdit` (the `setGameConfig` partial edit — each present
top-level field replaces the whole field, so the picker sends the full merged
5-slot `cues` block; noop if unchanged); `parseLightForm`/`planSetLight`
(#hex canonical lowercase, 0–8 intensity, directional requires a direction
|v|≤1 per component + norm ≥1e-6, ambient carries neither direction nor
castShadow; add = complete value, edit = changed fields, type switch =
complete value); `lightCounts` (the §23.10 1+1 scene limit);
`parseSurfaceForm`/`planSetSurface` (two #hex colors, roughness/metalness
0–1, emissiveIntensity 0–4; add complete / edit changed fields);
`SURFACE_PRESET_NAMES`/`SURFACE_PRESETS` (frozen display mirror of the §23.3.1a
rows — the backend applies the authoritative row); `parseModelAnimationForm`
(version 1…maxVersion, clipIndex integer ≥0, non-empty clipName, serialized
roles ≤4096 bytes) / `planSetModelAnimation` (assetId fixed to the entity's
model asset — the §23.8 step-5 conflict is a noop here; complete component
value); `planAnimatedReimport` (the §8.5.1 `animation: {entityId, roles}` for
the chosen referencing entity); `parseActivationForm`/`validateActivationCue`
(audio-kind preflight)/`planSetActivation` (`setComponent(gameZone,
{activation})` partial edit).

**`src/session/preview-audio.ts`** (new): `PreviewAudioOwner` — the packet's
"injected owner": the editor-page preview utility (NOT the binding §41.4.7
game owner — the editor boundary row cannot import game-host). RULE 1 gesture
(context created only by `unlock()` — the panel wires it to a real `isTrusted`
pointer; pre-gesture register/preview stay `blocked`, never throw); RULE 2
bounded decode on a copy (failure = one bounded diagnostic, never a throw);
RULE 3 ≤8 concurrent voices, at-cap drop with `preview_voice_cap`, never
queued; RULE 4 one live voice per cue; RULE 5 idempotent dispose (one close).
Deterministic with the injected `contextFactory`. Cue BYTES come from the
editor's authenticated content read (`client.assetByteResolver()` — the
authoring token is that read's credential, never a resource/data-URL/static
path).

**Projection/client/viewport:** `ProjectedEntity` gains `light`/`surface`/
`modelAnimation` (type-only imports from project-model; hydration +
`setComponent` convergence); `uploadAsset` carries `kind: 'model'|'audio'`
(the inspect kind selection) + the reinspect seam; `publishArgsFromProposal`
gains `kind` (required on create, §A3.5) + the §8.5.1 `animation`; the
viewport previews the authored `surface.color` on boxes (default when absent)
and renders light entities as a directional arrow / ambient sphere marker.

**UI:** `ui/MediaPanel.tsx` (new — five tabs: **Cues** (slot pickers over
audio-kind assets + the unlock/preview status + bounded diagnostics),
**Checkpoint** (activation appearance for the selected checkpoint zone),
**Lights** (1+1-limit create buttons + the light edit form), **Material**
(surface form + the three preset buttons → `applySurfacePreset`),
**Animation** (version select + the three role bindings, the inspected
clip-names hint)); `AssetBrowser.tsx` (accept `.glb,.wav`; the §8.5.1
**Animation mapping** section for a pending model reimport — entity picker +
three clip selects over the just-inspected clip names; publish disabled until
the mapping is complete — the command would be `field_missing`/stage-3
refused); `App.tsx` (media import flow with kind + referencing-entity
detection, the reimport role draft, the preview-owner lifecycle, all media
command callbacks over the existing envelope path); `editor.css` styles.

## Limitations

- The editor cannot query per-version `clipNames` from the catalog (only the
  inspect proposal carries them, and a truncated proposal can drop them);
  the animation tab therefore accepts free-form bindings (the backend's
  stage-3/5 validation is the authority) and shows the just-inspected names
  as a hint when still held.
- Cue preview bytes are fetched lazily on the first `▶` (no prefetch); a
  failed read is the ordinary network path.
- The preview owner is an editor utility, not the §41.4.7 binding owner
  (documented above; the game-host owner serves the play host).
- No settings/camera/game-config surface was touched (56's).
