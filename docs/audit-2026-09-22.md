# Audit — 2026-09-22

Independent audit of the tree as left by the packet workflow (tag
`archive/pre-audit-2026-09-22`, commit `0adc7aa`). Four area audits read the
code and ran the real bundles: backend over HTTP/WS, the editor in headless
Chrome, a scripted Beacon Reach playthrough on real Rapier, a standalone
export, and the MCP server over stdio.

## Summary

The foundations are real: the command pipeline (revision conflicts,
idempotent retries, atomic writes, undo as new transactions), module
boundaries, Rapier physics, keyboard/gamepad input, the fixed-step runtime,
the export bundle's independence from editor/server code, and a real MCP
server. But the product was never exercised as a user would use it. Every
milestone gate was a self-review; all browser, audio, and input checks were
left "UNVERIFIED"; no test touched the React app, viewport, gizmo, or
browser session client. At the audit the editor could not be used for
editing, and M2–M4 features were reachable only through test harnesses.

Build: green. Tests: 2252/2255 (the 3 failures were a brittle build-script
fixture test, now retired).
