## Outcome

The editor can import a GLB through the real authoring routes (stage → bounded
frames → inspect/job → `publishAsset` create/reimport) and query the catalog,
with the packet-26 shared GLB path now consumed by the viewport and asset
preview. Snapping is a local gesture option (0.25 m per world axis / 15° about
the gizmo axis / 0.25 uniform factor clamped `[0.01,100]`, round-half-away,
`1e-4` quantum, Shift disables one gesture) with zero commands during a drag,
exactly one on release, none on cancel, and one undo. All authoring decisions
live in pure modules; the React panel and viewport are thin.
