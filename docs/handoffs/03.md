## Outcome

The M1 architecture contract pack is finished (packets 00–03 → Gate A).
Four new normative contracts + the M1 acceptance plan, all version 0.1
pending Gate A, consistent with project-model v0.2 / commands v0.1 /
workspace v0.1 as-is (**no earlier contract was modified — and none
required changes**):

- **`docs/contracts/runtime.md` v0.1** — the runtime core contract: the
  **runtime snapshot** as the only input (`snapshotId = <projectId>@r<rev>`,
  normalized scene, re-validated and deep-frozen at `instantiateRuntime`);
  the `instantiated → running ⇄ stopped → disposed` lifecycle with exact
  transitions and error codes; the **separate mutable simulation state**
  (deep copy + `prev`/`curr` step pairs, `simTime = stepIndex / fixedStepHz`,
  determinism rules); **transform ownership** (authoring transform =
  backend, runtime transform = runtime state, render transform =
  read-only derived interpolation — no write-back, single owner per
  transform); **fixed 120 Hz steps with bounded catch-up**
  (`MAX_CATCHUP_STEPS = 8`, drop-and-resync anchor rule, module
  step isolation with rollback); the **interpolation policy** (component
  lerp + sign-aligned slerp on normalized *derived* quaternions, per
  project-model §10.1); the **built-in moving-box demonstration** with
  exact deterministic math (`x0 + 0.5·sin(2π·(n+1)/(120·4))`, all boxes,
  camera static); **structured diagnostics** (bounded 32-entry error ring,
  stable codes, adapter block reporting the selected WebGL 2 backend); and
  the normative non-goals — **no user scripts** (execution boundary
  deferred), no input, no physics, no graphs. Runtime imports
  `project-model` only: no filesystem, backend, editor, or MCP dependency.
- **`docs/contracts/sessions.md` v0.1** — the browser/backend session
  contract: authoring origin `O_A` vs **separate preview origin `O_P`**
  (two backend listeners; the preview listener serves only the static
  preview page — **no API, no credentials, ever**); exact ID/token syntaxes
  (`sess-`/`conn-`/`play-` + 32 hex, single-use 60 s `wsToken`, `relay-`);
  project-scoped bearer + exact-origin allowlist policy shapes (packet 09
  implements); the session lifecycle (establish/re-attach with **full
  state**, one active authoring session per project, `wsToken`-authed WS,
  heartbeats); command transport over HTTP (commands.md envelopes
  unchanged) + `mutation.applied` for browser/AI convergence; the
  **exhaustive WS event catalog**; the **gap rule + full-replacement
  resync** and **reconnect after dropped ack** (HTTP acks ⇒ commands.md
  replay semantics; WS re-attach ⇒ full state); **gesture preview/commit**
  (zero server traffic mid-gesture, one `setTransform` on release,
  bounded conflict recovery that explains — never silently loses — a
  failed edit); **play sessions** (start requires the registered browser
  owner, frozen snapshot revision, `active → presented → stopping →
  stopped` machine, **play/screenshot/diagnostics routed to the explicitly
  selected browser; no browser ⇒ structured `session_unavailable`**,
  screenshot responses always carry `snapshotId` + `revision`); **bounded
  logs/errors** (128-entry session log ring, stable codes, payload/timeout
  constants); and the **checked message bridge**: exact-origin/source
  validation (never `"*"`), the handshake sequence, and the exhaustive
  `tl.*` allowlist, plus dev/deploy origin configuration.
- **`docs/contracts/export.md` v0.1** — the standalone export: input is one
  immutable snapshot read through the workspace service (admin operation,
  not MCP in M1); the static output tree
  (`index.html`, `js/main.js`, `snapshot.json`, `meta.json`) with
  **relative paths only**; the bundle is the **same runtime as play mode**
  with an exact import graph (metafile-verified, no editor/server/MCP/node
  modules), a single relative `fetch(./snapshot.json)`, and a **9-pattern
  forbidden-content scan** (no authoring URLs, no `/api/v1/`, no Node
  imports, no MCP endpoints, no credentials — no silent exceptions);
  `meta.json` records engine + dependency versions; the 6-code validation
  pipeline with no-partial-artifact semantics; and the **reproducibility
  scope stated exactly** (byte-identical `snapshot.json`/bundle, `meta.json`
  equal except `exportedAt`). One small supported scene — not a general
  asset build system.
- **`docs/contracts/dependencies.md` v0.1** — the module/dependency
  contract: the 10 units (create **only when implemented**), each unit's
  public `exports` surface, the **allowed import-edge tables** in both
  planes (node-side per package + the exact editor/preview/export bundle
  graphs), the forbidden edges (`runtime → three`, `mcp-adapter → backend`
  except `/services`, `editor → workspace`, no hidden globals, no duplicate
  mutation path — `workspace.runCommand` is the sole executor), the
  **enforceable boundary checks** (static import-graph check, negative
  fixture proof, esbuild metafile bundle checks, content scan, strict
  typecheck, exact-pin `check-deps`), the **narrow module registration
  mechanism** (compile-time simulation-module registry; M1 contents =
  exactly `thirdlight.demo:box-motion`; deliberately unable to load
  untrusted code), and the **recorded M1 stack per decision 0001 §3
  including the 2026-09-17 ruling** (React 19.3.0 + types, `editor` only;
  esbuild TSX loader; **React is the only permitted UI framework, scoped to
  editor panels; `three-adapter`/`runtime` framework-free; no web framework
  anywhere**).
- **`docs/planning/m1-acceptance.md` v0.1** — the **exact M1 acceptance
  scenario** (14-step integrated loop on a disposable project: create →
  author → gizmo gesture with zero mid-gesture traffic → undo/redo →
  backend restart survives → isolated play with displayed snapshot revision
  → stop/repeat disposal → MCP edit converges in the browser → stale edit
  rejected → screenshot with revision + no-browser structured
  unavailable → export verified against an independent static server with
  the backend stopped, reproducibility diff → external-change +
  disconnect/resync failure modes), the **requirement → future-check map**
  linking every normative requirement of all six contracts to the packet,
  method, and evidence that proves it, and the **explicit not-M1 list**
  (input simulation, physics, graphs, user scripts, play write-back,
  prefabs/assets, rename/reorder, collaboration, WebGPU, headless
  rendering, general asset builds, backups/mobile/multiplayer/RPG).
