Owner pre-approval: **owner pre-approval (autonomous M2 build instruction,
2026-09-18); final manual review pending.** No git commit was made.

## Outcome

The editor can capture the current selection into an immutable prefab definition
(`createPrefab`, "Create Prefab Definition"), materialize independent copies
(`instantiatePrefab`, "Place Copy", one transaction per copy) with one legal
initial declared-property override, and edit one copy's typed properties through
an ordinary `setBehaviorProperties` command. All authoring decisions live in
pure Node-tested modules; the React panels are thin. No linked-prefab, apply,
revert, variant or propagation control exists: copies are labelled "Copy of
<displayName> — copies are independent". Controls derive **only** from published
declaration data (typed default/constraints), never by evaluating script code.
Collider/controller appear as read-only contract-shape controls (C28-1).
