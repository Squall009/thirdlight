## Defect found and repaired (in-scope): the settle race

`settleIfComplete` was gated on `handle.state() === 'pending'`, but between
a loader promise resolving and the adapter's `.then` attach callback there
is a microtask gap where state is non-pending yet attach has not run —
settle resolved early (observed `{instances:4, animations:0}` vs counters
`{instances:6, animations:2}`). Fix: an explicit `pendingCount` assigned
after row collection, decremented **inside** each completion callback
before `settleIfComplete` (the 0-byte discard path decrements too).
Regression test: two-asset microtask race settles only after both attach.

## Defect discovered and refiled (out-of-boundary): the committed
template/sample `courier.glb` is corrupt

`samples/beacon-reach/assets/model/courier.glb` (byte-identical in
`fixtures/m4/templates/…/sources/model/courier.glb`; digest
`d62fc659f569b42c0f828ebf08eac661b5afe4312f81266a178ea3d3e25678be`)
carries broken animation data: the real pinned GLTFLoader parses it, but
every clip track's key times are a box's 36 vertex indices (values 0..7;
79 non-monotonic transitions of 179 per track) → the substrate rejects with
`asset_clip_invalid`. Root cause: `samples/beacon-reach/tools/generate-assets.mjs`
`buildRigidModel` — `const tAcc = 3 + samplers.length * 2;` miscomputes the
sampler input accessor index (for the 2-part model, channel 1's `input`
points at Arm's index accessor instead of its times accessor). Latent in M3
(sample courier was static-only; the template recipe binds clips). Both
files are outside 69's may-edit boundary and digest-pinned in their own
contracts → **refiled to the sample/template repair packets** (72–74 will
meet it again). 69's evidence uses packet-owned GLB bytes of identical
structure (same assetIds, same clip names/order Idle/Run/Airborne, 4.0 s)
generated by `tools/glb-build.mts` (deterministic; self-checked through the
real pinned GLTFLoader) — recorded in the fixture index `sourceSubstitution`
block; the scene document and committed clip bindings are unchanged.
