## P1 finding — accepted preview CSP blocks Rapier WASM (contract change needed)

With `sessions.md` §17.4's production preview CSP (`script-src 'self'`) the real
browser refuses every WebAssembly compilation, so the pinned `rapier2d-compat`
adapter returns `physics_init_failed`/`wasm_unavailable`; **editor Play on a
CSP-compliant preview origin could never initialize physics**. Isolation:
`engine.json` (production CSP) FAIL, `engine-nocsp.json` PASS,
`engine-csp-wasm.json` (production CSP + `'wasm-unsafe-eval'`) PASS.

Proposed one-token diff (owned by packet 42, **not applied**): add
`'wasm-unsafe-eval'` to `script-src` in `sessions.md` §17.4. Recorded in
`planning/m3-contracts/baseline.md` §2 with consequences (wasm-only permission;
export/static serving must state its own policy; preview iframe needs
`allow="gamepad"`). Per AGENTS.md an accepted contract is binding, so the change
goes through Gate K review + promotion; nothing edits it silently.
