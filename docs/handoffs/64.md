## Design of record (`planning/m4-contracts/delivery.md`)

- **Model bytes** flow wrapper → host-config/adapter options (no fetch in
  host/adapter). The adapter owns the resource store, model prepares and
  role controllers behind the **unchanged** `HostRenderAdapter` surface —
  zero host changes for model attachment.
- **Single loop:** `hostFrame` → `renderFrame` = sync transforms → one
  `update(delta)` per live controller (view = committed `GameView`;
  non-player ⇒ constant neutral motion) → render. No second rAF, no mixer
  listener, no independent clock; delta clamped `[0, 0.25]` (hidden/
  suspend-resume is a fresh anchor — no fast-forward).
- **Holder parenting:** the model root is a **child of the entity holder**
  (the runtime moves the holder; the mixer writes only weights/time — no
  physics-root animation writes; A6 root-motion negative enforced).
- **Corrupt vs degraded** closed table L1–L9 (§2.7): corrupt = hard mount
  failure with closed codes; degraded = accepted capability states (no
  WebGL, audio blocked, L6 static + diagnostic). Pinned reimport is a
  no-op for the active play (new `snapshotId`/`contentId` only).
- **Behavior scope (CC-55-3):** the M4 delivered profile is **built-in-only**
  with a C14-style explicit refusal for source-bearing behavior scenes (not
  silently erased support). CC-55-3a deferred with an explicit record;
  CC-55-3b (HUD wording) renumbered, bounded to a packet-70 fix.
- **Queries:** no second catalog, no default-based reconnect guess, no new
  mutable settings store — the panel hydrates from `querySettings`
  (explicit/resolved) and advances on applied `setSettings` change records.
