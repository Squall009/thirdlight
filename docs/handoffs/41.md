## §18.1 rule-3 replacement (summary)

The only accepted model rule replaced: rule 3 now carries a bounded exception
for `components.modelAnimation.roles[role] = { clipIndex, clipName }` — scene
data only; scoped to one immutable `(assetId, version)` and invalidated by
reimport; validated against the version's real clip list at publication and
re-checked at load; never a lookup key (`clipName` must equal
`clips[clipIndex].name`); no other persisted internal glTF name/index anywhere.

## Audio byte accounting (summary)

Canonical file = 44-byte header + `dataBytes` PCM. 48 kHz mono s16 ⇒
`blockAlign 2`, `byteRate 96000`, `frames = dataBytes/2`,
`durationMs = floor(frames/48)`, `sourceBytes = 44 + dataBytes`,
`riffSize = 36 + dataBytes`. `dataBytes ≤ 192000` ⟺ 96 000 frames ⟺ 2000 ms ⟺
`sourceBytes ≤ 192044`; a file above 196 608 bytes is rejected at stage 1 before
the profile cap is read.
