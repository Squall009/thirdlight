## 1. Group A1 — deep isolation + JSON-safe diagnostics (R10, R17) — 2026-09-18

**Scope.** Exactly R10 + R17 of `docs/reviews/2026-09-18-commits.md`
(work-order group A1). The amended `docs/contracts/workspace.md` (dabfcff)
is the authority; the new claim-file/evidence-failure machinery is a later
group's work and is NOT started here.

**Findings fixed.**

- **R10 (P1, mutable authoritative state behind public query/ack objects).**
  Chosen isolation: a **deep freeze at the public API boundary** (not deep
copies) — queries are the hot path (workspace.md §5.3 immediate in-memory
  reads); a copy would re-allocate up to 1024 entities per query, while a
  freeze touches each shared object once and later exports/acks/replays
  skip it (`Object.isFrozen`, idempotent). Every public return —
  `runCommand` (fresh ack, replayed ack, failures), `query` (entity/
  subtree/scene/manifest/history/workspace + error payloads), all five
  operator operations and the scan report (`lastScan` getter included) —
  is deep-frozen (`deepFreeze`, `src/isolate.ts`); freezing recurses through
  the shared references, so the published scene entities, manifest, retry-
  record results and history change data become unreachable-for-mutation
  the moment they are exported. `runCommand` remains the single mutator of
  authoritative state (the commands layer is pure — verified: new object
  graphs, stored inverse/forward values deep-cloned on re-application —
  so frozen published snapshots never break the next mutation). The replay
  path still spreads the record top level (contract: byte-identical except
  `duplicated`), but its nested containers are frozen, so a replayed ack
  can no longer write through to the persisted record. A strict-mode write
  attempt throws `TypeError`; a sloppy-mode one silently no-ops — either
  way the state is untouched.
- **R17 (P2, unserializable validation errors).** Replaced the raw
  `error.found = <caller value>` with a bounded, JSON-safe diagnostic
  conversion applied at ALL public-input validation sites in
  `packages/workspace/src/errors.ts` (`invalidRequest`, `fieldUnexpected`,
  `fieldTypeError`, `fieldValueType`). Limits chosen: depth 8; 64 total
  nodes (containers + leaves); strings (values AND keys) truncated at 200
  chars with a total-length marker; ≤ 64 keys per object (rest ⇒ summary
  key); identity seen-set for cycles ⇒ marker string; unsupported
  primitives/exotics (BigInt/Function/Symbol/undefined/Date/Map/Set/typed
  arrays/class instances) ⇒ their type name as a string; non-finite
  numbers ⇒ string form. Output is always JSON-serializable and ≤ ≈ 30 KB
  for any caller input. Error codes/paths/messages unchanged — only the
  `found` representation.
